# src/lib/

Clients et utilitaires partagés : `supabase.ts` (client browser), `supabase-server.ts`
(client pour server components) et `utils.ts` (fonctions utilitaires générales).
Toute la logique réutilisable hors composants vit ici, et les imports Supabase passent par ce dossier.

Responsable : **Agent Frontend**.
